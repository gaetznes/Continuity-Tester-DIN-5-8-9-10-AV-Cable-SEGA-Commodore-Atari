# Continuity-Tester-DIN-5-8-9-10-AV-Cable-SEGA-Commodore-Atari

Simple Portable Continuity Tester for Testing RCA AV Cables for several Console &amp; Computers that use din connectors. 

There are two revision below. One for 180 degree RCA Phono Jacks (tht), and the other is 90 degree Jacks that are smd mounted.

The goal is this can fit in a pocket, weigh less than 100grams. Regardless of where you are. At the bench, a flea market, or used store. You want to be able to verify if a AV cable works. This version will focus on DIN to RCA Phono cables plus I kept the Nintendo SNES N64 NGC connector. This Project is untested as of listing this. Once it's been built, confirmation pictures will be uploaded. 

The Din Connectors are as followed

5pin: Atari A8 computers and Vic 20

8pin: Commodore 64, Sega Master System, and Sega Genesis Model 1

9pin Mini Din: Sega Genesis

10pin Mini Din: Sega Saturn

Led placement. If you install Leds at "Indicator GND Check", Use the jumper pads next to GND LED By-Pass. 
If not, solder all 3 Jumper pads next to "Indicator GND Check", and place a Led below the GND LED By-Pass.
For Green LED's, use 2.2k. If battery life is your main concern and looking for brightness consistency, use 750r and all Red Leds.
